# معامل رامي مختار للتحاليل الطبية (RT Labs) - منصة مكافآت وجوائز المرضى

منصة تفاعلية للمرضى تتيح لهم خوض مسابقات ترفيهية يومية (عجلة الحظ، كروت الخدش الممغنطة، مسابقة المعلومات الطبية) والحصول على نسب خصم وكروت فحص مجانية لتشجيع الفحص المبكر وزيادة تردد المرضى على فروع المعمل.

## 🌟 المميزات الرئيسية
- **دخول مباشر وسلس:** رابط مباشر للمريض بدون تسجيل دخول معقد.
- **عجلة الحظ (Lucky Spin Wheel):** دوران تفاعلي بفيزياء حركة ومؤثرات صوتية وجوائز قابلة للتخصيص.
- **كروت الخدش الفورية (Interactive Scratch Card):** كشط تفاعلي عبر تقنية HTML5 Canvas لكشف المفاجآت والخصومات.
- **تحدي المعلومات الطبية (Health Trivia):** أسئلة طبية وتوعوية شيقة مع جوائز مؤكدة وشروحات صحية مفيدة.
- **توليد كوبون خصم رسمي:** كارت خصم طبي معتمد بباركود وكود فريد (مثل `RT-2026-X892`).
- **إرسال مباشر إلى واتساب المعمل:** زر بنقرة واحدة ينشئ رسالة تأكيد رسمية مباشرة إلى رقم المعمل المسجل لتفعيل الخصم.
- **لوحة تحكم كاملة للإدارة (Admin Panel):**
  - إدارة الهدايا ونسب الخصم وألوانها ونسب الفوز.
  - بنك أفكار تسويقية مبتكرة للمعمل جاهزة للإضافة بنقرة واحدة.
  - سجل الفائزين وتأكيد الحجوزات وتصدير تقرير Excel / CSV.
  - إدارة رقم الواتساب المسجل، الخط الساخن، الفروع وصلاحية الكوبونات.

## 🚀 التشغيل محلياً
```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev

# بناء النسخة النهائية
npm run build
```
